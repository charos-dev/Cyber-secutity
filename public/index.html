01 / IP Scanner

Qurilma tarmoqda bormi yoki yo‘qmi?

IP Scanner lokal tarmoqdagi qurilma javob berayotganini tekshiradi. Masalan, router, kompyuter yoki server ishlayaptimi, tarmoqda ko‘rinadimi, hostname topiladimi - shu savollarga javob beradi.

Nega kerak?

Tarmoqda muammo bo‘lsa, avval qurilma umuman online ekanini bilish kerak. Bu troubleshootingning birinchi bosqichi.

Qanday ishlaydi?

Server IP manzilga ping yuboradi va DNS reverse lookup orqali hostname topishga harakat qiladi.

Qanday ishlatish kerak?

Inputga 127.0.0.1 yoki 192.168.1.1 kiriting va tekshirish tugmasini bosing.

Faqat o‘zingizga tegishli lokal IP manzillarni tekshiring.

02 / Port Scanner

Qaysi xizmatlar ochiq ekanini aniqlash

Port Scanner qurilmada qaysi portlar ochiq ekanini ko‘rsatadi. Ochiq port degani o‘sha qurilmada ma'lum xizmat ishlashi mumkin: masalan, 80 HTTP, 443 HTTPS, 22 SSH.

Nega kerak?

Keraksiz ochiq portlar xavfsizlik xavfini oshiradi. Administratorlar faqat kerakli xizmatlar ochiq ekanini tekshiradi.

Nima uchun bunday qilinadi?

Har bir ochiq port tizimga kirish nuqtasi bo‘lishi mumkin. Shuning uchun ularni nazorat qilish muhim.

Qo‘llanma

IP kiriting, portlarni vergul bilan yozing va tekshiring. Natijada open: true bo‘lgan portlar ko‘rinadi.

Begona sayt yoki serverlarni scan qilish mumkin emas. Faqat ruxsat berilgan IP lar.

Common: 80 443 22 3000

03 / IP Log Analyzer

Log ichidan shubhali IP larni topish

Log Analyzer server loglaridagi IP manzillarni sanaydi. Qaysi IP ko‘p kirgan, qaysi qatorda failed login bo‘lgan, qaysi IP limitdan oshganini alohida chiqaradi.

Nega kerak?

Hujumlar ko‘pincha loglarda iz qoldiradi. Failed login, 401, 403 yoki juda ko‘p request xavf belgisi bo‘lishi mumkin.

Nima qilish kerak?

Log matnini kiriting va “shubhali limit” qiymatini belgilang. Limitdan oshgan IP suspicious bo‘ladi.

Natijani qanday tushunish kerak?

topIps eng faol IP larni, suspiciousIps esa limitdan oshgan IP larni bildiradi.

Haqiqiy logdan parol, token, cookie kabi maxfiy ma'lumotlarni olib tashlang.

04 / DDoS Detection

Juda ko‘p request yuborayotgan IP ni aniqlash

DDoS Detection bo‘limi bir IP qisqa vaqt ichida juda ko‘p request yuboryaptimi, shuni statistik usulda ko‘rsatadi. Bu haqiqiy himoya tizimi emas, lekin hujum belgisini tushuntirish uchun yaxshi demo.

Nega kerak?

Serverga haddan tashqari ko‘p request kelsa, sayt sekinlashadi yoki ishlamay qoladi.

Nima uchun limit qo‘yiladi?

Normal foydalanuvchi odatda juda ko‘p request yubormaydi. Limitdan oshish suspicious activity sifatida ko‘riladi.

Qo‘llanma

Request loglarini kiriting, limitni belgilang. Status Possible DDoS bo‘lsa, IP juda faol.

Haqiqiy loyihada rate limit, firewall, CDN va monitoring bilan himoya qilinadi.

05 / GeoIP Tracker

Public IP qayerga tegishli?

GeoIP Tracker public IP manzilning taxminiy joylashuvi va internet provayderini ko‘rsatadi. Bu usul foydalanuvchining aniq manzilini emas, IP ro‘yxatdan o‘tgan hududni ko‘rsatadi.

Nega kerak?

Loglarda notanish IP ko‘rinsa, uning qaysi davlat yoki providerga tegishli ekanini tezda ko‘rish mumkin.

Nima uchun public IP kerak?

Private IP lar faqat lokal tarmoq ichida ishlaydi. Internetdagi joylashuv faqat public IP uchun aniqlanadi.

Qo‘llanma

8.8.8.8 kabi public IP kiriting va natijada country, city, ISP maydonlarini ko‘ring.

GeoIP ma'lumotlari taxminiy bo‘ladi, 100% aniq manzil deb qabul qilinmaydi.
